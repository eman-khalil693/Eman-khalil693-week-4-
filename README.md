# JavaScript Task Management Application

## Week 4 - Web Development Internship

This project is a Task Management Application developed using HTML5, CSS3, and Vanilla JavaScript.

The purpose of this project is to practice JavaScript fundamentals, DOM manipulation, events, form validation, and localStorage.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser localStorage

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- View all tasks
- Filter active tasks
- Filter completed tasks
- Form and input validation
- Save tasks using localStorage
- Retrieve tasks after page refresh
- Responsive design for mobile devices

---

## How It Works

Users can enter a task in the input field and click the Add Task button.

Each task can be:

- Marked as completed
- Edited
- Deleted

The application stores tasks in the browser's localStorage, so tasks remain available after refreshing the page.
